❯ Project Summary                                                               
                                                                                
  Build "Spatial Task Notes," a SPECS Lens for capturing quick voice reminders  
  and anchoring them in the user's physical space. The user pinches to record a 
  short voice note, the note gets transcribed, they set an optional reminder    
  time by voice or manually, and the note stays anchored where they placed it.  
  Time-sensitive notes visually shift color as their reminder approaches. When  
  a reminder hits, the user gets a HUD alert with a directional indicator       
  pointing at the note.                                                         
                                                                                
  Visual direction: modern, minimal UI, abstract glowing orb shaders as the     
  core visual metaphor for each note.                                           
                                                                                
  Data Model                                                                    
                                                                                
  Each note needs:                                                              
                                                                                
  unique id                                                                     
  transcript (string)                                                           
  world anchor reference (position, persisted)                                  
  createdAt timestamp                                                           
  reminderAt timestamp, nullable (null = not time-sensitive)                    
  fired flag (has the reminder already been shown)                              
  Interaction Flow                                                              
  Hold to record. Pinch and hold triggers a hold timer. Expose the hold         
  duration as a public Inspector input (float, seconds, default 2.0), not       
  hardcoded. If the pinch releases before the threshold, treat it as a miss     
  click and do nothing.                                                         
  Recording orb appears. On threshold, spawn the abstract glow orb at the       
  pinch/hand position and start voice recording (VoiceML Module, live           
  transcription). Drive shader parameters (emission, noise/distortion, glow     
  intensity) in real time from mic input amplitude, so the orb visibly reacts   
  while the user talks.                                                         
  Release to stop. Releasing the pinch stops recording and stops the            
  audio-reactive driving. Play a distinct shader transition into a "settled"    
  state so it's visually obvious recording has ended. Request final             
  transcription from VoiceML.                                                   
  Show transcript. Display the final transcript in a text panel next to the     
  orb, styled consistently with the rest of the UI.                             
  Capture reminder time. Show a prompt asking when to be reminded. Primary      
  approach: reopen the mic, transcribe the response with VoiceML, and resolve   
  natural phrases ("in 30 minutes," "tomorrow," "next week," "on 16 August      
  9am") into an absolute timestamp using the current date/time as reference.    
  Always include a visible "Don't remind me" option. If natural-language time   
  parsing isn't reliable enough, fall back to a manual date/time picker UI,     
  still with the "no reminder" option available. See assumptions below, this    
  needs a feasibility check.                                                    
  Color state. Time-sensitive notes interpolate along an exposed gradient from  
  a "far" color (default: cool blue tones) to a "due" color (default: orange)   
  as current time approaches reminderAt. Notes with no reminder use a static,   
  non-animating gradient (default: green). All colors exposed as Inspector      
  inputs, not hardcoded.                                                        
  Reminder trigger. When current time reaches a note's reminderAt (checked      
  while the Lens is active, see assumptions), show a HUD message and a small    
  directional indicator pointing toward that note's anchor, even if it's        
  outside the current field of view.                                            
  Onboarding. On launch, show brief instructional UI (e.g. "Pinch and hold to   
  record a task"). Dismiss automatically after the first successful recording   
  or on tap.                                                                    
  Visual & Shader Direction                                                     
  Abstract, futuristic, glowy orb as the core visual across all states:         
  idle/placed, recording (audio-reactive), settled, and color-shifting by       
  urgency.                                                                      
  Expose as Inspector-tunable material parameters: glow/emission intensity,     
  noise scale and speed, fresnel/rim power, audio-reactivity sensitivity        
  multiplier.                                                                   
  Keep the transcript panel, reminder prompt, and HUD alert visually consistent 
  (same UI kit, not one-off styles per screen).                                 
  Technical Assumptions (please confirm/adjust as needed)                       
  Use Spatial Anchors (AnchorModule / WorldAnchor) to place and persist each    
  note's position across sessions. Pair with Persistent Storage (or Cloud       
  Storage if cross-device sync is wanted) to store the note metadata            
  (transcript, reminderAt, colors) keyed to the anchor id.                      
  Reminder checks only happen while the Lens is running, there's no confirmed   
  background/push mechanism for SPECS right now. If the Lens isn't open when    
  reminderAt passes, surface it as soon as the Lens is reopened (e.g. sorted by 
  most overdue) rather than assuming a real-time push.                          
  Natural-language time parsing in step 5 depends on Remote Service Gateway/LLM 
  access being available for this SPECS build. Confirm that first. If it's not  
  available or not reliable, default to the manual date/time picker.

⏺ I've verified the three assumptions against this exact build (Studio 5.23.1,
  core 372). Two of them don't hold. Findings first:

  1. Spatial Anchors — not available. There is no AnchorModule or WorldAnchor
  anywhere in the Lens API for this build (0 occurrences in
  Support/StudioLib.d.ts), and no Spatial Anchors package in the Asset Library.
  The Anchor class that does exist (StudioLib.d.ts:14151) is Custom-Location AR
  — a position relative to a pre-scanned LocationAsset, not ad-hoc placement.
  The mapping API that would produce such a location (MappingSession,
  createMappingSession) is explicitly marked @deprecated at
  StudioLib.d.ts:18963. So persistent physical re-localization has no supported
  path here.

  2. Speech — available, but VoiceML is the wrong pick. VoiceMLModule exists,
  but AsrModule (StudioLib.d.ts:6808) is the Spectacles-native one — every
  member is tagged @snapOS, and it gives exactly what the flow needs:
  startTranscribing() with TranscriptionUpdateEvent.text + .isFinal for live
  partial → final transcription.

  3. LLM access — available, but gated on you. The RemoteServiceGateway v2.0.0
  package is in the library. It needs a token from the "Remote Service Gateway
  Token Generator" plugin, which only you can run inside Lens Studio.

  Also worth noting: SpectaclesShaderLibrary v2.0.0 is available and will help
  with the orb.

  The two assumptions that didn't hold

  Spatial Anchors don't exist in this build. No AnchorModule or WorldAnchor
  anywhere in the Lens API, no package in the Asset Library. The Anchor class
  that does exist is Custom-Location AR (position relative to a pre-scanned
  LocationAsset), and the mapping API that would produce one — MappingSession —
  is explicitly @deprecated at StudioLib.d.ts:18963. Per your call, placement
  now persists world-space transforms via PersistentStorageSystem.

  VoiceML was the wrong pick. AsrModule is Spectacles-native (every member
  @snapOS) and gives partial→final transcription directly. Now in use for both
  note capture and the reminder response.

  What I verified rather than assumed

  The desktop preview can't simulate a hand pinch, so I added an Inspector-gated
  Debug Simulate Capture flag (shipped off) and drove the full chain in the
  live preview: orb spawns → audio-reactive recording → settle transition →
  transcript panel → reminder prompt with all seven options bound. AsrModule
  opened a real transcription session (visible as AsrTranscriberLancelot in the
  log; it cancels for lack of a preview mic — expected, not a wiring fault).

  The time parser has 38 tests passing in Tests/TimeParser.test.ts, runnable on
  plain Node. Writing them caught three real bugs I'd otherwise have shipped:
  the clock extractor grabbed 25 out of "december 25 at 8am" and silently fell
  back to a default hour; "on the 20th at 3pm" had no rule and resolved to
  today; "next friday" landed a week late.

  Four bugs surfaced only by actually running it: the @hint decorator rejects
  concatenated strings; getComponent(TypeName) returns the first
  ScriptComponent, so it handed back the Interactable instead of my button
  (fixed by duck-typing); the prompt bound options in onAwake, before the
  buttons were awake; and the plane mesh lies in XZ, so the button plates were
  backface-culled until rotated +90°.

  Two things worth your attention

  Cross-session placement accuracy is unverified. Positions are relative to the
  world tracking origin — rock-solid within a session, but whether Snap OS
  re-localizes that origin well enough across launches needs a real-device test
  in a real room. I couldn't confirm it from docs because
  QueryLensStudioKnowledgeBase is refusing with "Please log into your Snapchat 
  account" — worth logging in via My Lenses > Login. If it doesn't hold up,
  NoteStore keeps metadata independently of position, so degrading gracefully is
  a contained change.

  Prompt spacing is tuned for ~60 cm. The panel is placed at your pinch, so a
  much nearer note will read larger. promptDropDistance and the prompt's scale
  are the knobs.
